# Chirp Social Clone

A Firebase-powered social application with Google authentication and live post interactions.

## Features

- Google authentication
- Live social feed
- Post creation
- Firebase-backed data
- Responsive interface

## Built With

- React
- Vite
- JavaScript
- Firebase

## Requirements

- Node.js 20 or newer
- npm

## Installation

```bash
git clone https://github.com/Miingo954/chirp-social-clone.git
cd chirp-social-clone
npm install
```

## Run Locally

```bash
npm run dev
```

Open the local URL shown in your terminal.

## Available Scripts

```bash
npm run dev
npm run build
```
